# 01. Executive Overview

## Producto
**Atelier de Lujo Pro** es una plataforma SaaS multi-tenant para talleres de joyería premium que prestan servicio a múltiples joyerías minoristas.

## Flujo correcto
1. La joyería cliente crea solicitud de reparación (con fotos y descripción).
2. El taller recibe, verifica y completa selección técnica de servicios.
3. El sistema genera cotización y seguimiento del proceso completo.
4. Cliente aprueba/rechaza y luego rastrea avances hasta entrega.

## Diferenciador crítico
El sistema aplica **filtrado inteligente de servicios por tipo de joya**, mostrando solo categorías relevantes para evitar errores de cotización y acelerar operación.

## Capacidades clave
- Catálogo de servicios completo y editable.
- Motor de precios con multiplicadores por material.
- Offline-first con sincronización automática.
- Mensajería con notas internas no visibles al cliente.
- Landing pública opcional y guest mode con solicitudes locales.
